## 三、API 兼容性结论（统一 SDK 教学）

**核心结论：OpenAI 兼容格式（chat/completions）已是行业事实标准。教程可以用 `openai` npm 包 + 切换 baseURL 一套代码教全部主流模型**，仅 Anthropic 原生 API 例外（但可通过 OpenRouter 或其官方 `@anthropic-ai/sdk` 解决）。

| 厂商 | OpenAI 兼容？ | Base URL（chat/completions） | 官方核实来源 |
|---|---|---|---|
| OpenAI | 原生（另推 Responses API） | `https://api.openai.com/v1` | — |
| **DeepSeek** | **完全兼容**（另有 Anthropic 兼容端点） | `https://api.deepseek.com`（Anthropic 格式：`https://api.deepseek.com/anthropic`） | [官方文档](https://api-docs.deepseek.com/quick_start/pricing)明示"可以用 OpenAI/Anthropic SDK 访问" |

### OpenRouter 定位（2026-10 核实）

- 单一 API 聚合数百模型，自动 failover、自动选最便宜供应商；模型价格与厂商直连**同价无加价**。
- 费用：充值手续费——信用卡（Stripe）**5.5%（最低 $0.80）**、加密货币（USDC via Coinbase）**5%**；支持**支付宝（AliPay）**，对中国用户友好。
- BYOK（自带厂商 key）：每月 $25,000 列价用量内免手续费，超出部分 5%。
- 同意 prompt 日志记录可再享 1% 折扣；credits 购买后 24h 内可退（手续费不退、crypto 不退），一年未用可能过期。
- 对国内用户的价值：一个美元钱包即可调 GPT/Claude/Gemini/DeepSeek/GLM/Kimi 全家，无需逐家注册外币卡；缺点是需网络可达 openrouter.ai。

### 对教程的直接建议

1. **第一课就教"环境变量三件套"**：`BASE_URL` / `API_KEY` / `MODEL`，全部示例用 `openai` npm 包实例化，让学员在 DeepSeek（默认）↔ GLM ↔ Kimi ↔ Gemini ↔ OpenRouter 之间无缝切换。
2. **Anthropic 单独一节**：介绍 `@anthropic-ai/sdk` 的 Messages API 差异（system 消息、cache_control 字段），并演示"通过 OpenRouter 用 OpenAI 格式调 Claude"的捷径。
3. **Prompt Caching 值得单独一章**：DeepSeek（命中 ¥0.02）、Anthropic（读 0.1x 起、5.5 代低至 2.5%）、Kimi（命中 ¥2 vs 未命中 ¥20）差异显著，是 TS 应用里实打实的省钱特性。
